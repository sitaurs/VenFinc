## Release gates

1. Semua requirement AC lulus atau mempunyai izin waiver tertulis untuk noncritical; uang, tenant privacy, WA policy, consent, credential leakage dan data deletion critical **tidak dapat di-waive**.
2. Seluruh desain mendapat snapshot mobile+desktop dan state kosong/loading/error, ID/EN, light/dark; 90 ID harus lengkap.
3. Bukti end-to-end riil untuk auth, RLS, GOWA multi-session, 9router vision, OCR fallback, Neon posting, R2 private, offline dedup.
4. Restore rehearsal benar-benar berhasil, batas biaya terpantau, privasi/WA/legal/email gates memperoleh keputusan GO.
5. Developer/QA/operator menyimpan trace yang teredaksi dan pemilik produk memberi persetujuan deploy.
